# iCaNova colour system

## Primary

| Token | HEX | Purpose |
| ----- | --- | ------- |
| Graphite | `#111820` | Primary dark background |
| Warm White | `#F2F1ED` | Primary light background / dark-theme text |
| Deep Navy | `#263746` | Secondary surfaces / navigation |

## Supporting

| Token | HEX | Purpose |
| ----- | --- | ------- |
| Titanium Silver | `#B8BABC` | Secondary details |
| Light Silver | `#D8D9D7` | Light borders and dividers |
| Industrial Steel | `#637B83` | Technical supporting colour |
| Muted Copper | `#A8754D` | Occasional accent (not dominant) |

## Status (not brand colours)

| Status | HEX |
| ------ | --- |
| Success / Online | `#24845B` |
| Warning | `#D18A26` |
| Critical / Error | `#C64747` |
| Information | `#477CA8` |
| Offline / Unknown | `#707780` |

Always pair status colour with text or an icon.
