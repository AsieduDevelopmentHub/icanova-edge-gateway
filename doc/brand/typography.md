# iCaNova typography

| Usage | Typeface |
| ----- | -------- |
| Brand headings | Manrope (500–700) |
| Application UI and body | Inter (400–600) |
| Technical data | IBM Plex Mono (400–500) |

CSS variables (web):

```css
--font-display: "Manrope", system-ui, sans-serif;
--font-body: "Inter", system-ui, sans-serif;
--font-mono: "IBM Plex Mono", ui-monospace, monospace;
```

Firmware and serial documentation stay on readable system fonts. Do not load webfonts into the ESP32 embedded page.
